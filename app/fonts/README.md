# Caption fonts

All fonts here come from [Google Fonts](https://fonts.google.com) and are licensed under the
SIL Open Font License 1.1 (full text in `OFL.txt`): Cairo, Tajawal, IBM Plex Sans Arabic,
Readex Pro, Noto Kufi Arabic, Noto Naskh Arabic, Noto Sans Tifinagh, Amiri, Lalezar, Inter,
Montserrat, Poppins, Anton, Bebas Neue.

Variable fonts (Cairo, Readex Pro, Noto Kufi/Naskh Arabic, Inter, Montserrat) were instanced
to static Regular (400) and Bold (700) files with fontTools, because libass cannot select a
bold weight from a variable font.
